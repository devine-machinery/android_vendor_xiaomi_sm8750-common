# android_vendor_xiaomi_sm8750-common

Common vendor blobs for Xiaomi SM8750 from HyperOS 4 CN **OS4.0.0.22.XOCCNXM**.

Requires **git-lfs**. CAF display collisions (`libdisplayconfig.qti`, `libqdMetaData`, `libsdmutils`, `vendor.qti.hardware.display.snapalloc-impl`) are `enabled: false`.
Fingerprint HAL is `android.hardware.biometrics.fingerprint-service.xiaomi_prebuilt`.

```bash
git lfs install
git clone -b lineage-23.2 https://github.com/devine-machinery/android_vendor_xiaomi_sm8750-common.git
```
